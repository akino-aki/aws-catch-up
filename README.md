# aws-catch-up

AWS のアップデート（AWS Japan ブログの「週刊AWS」に載ったもの）を 1 件ずつ調べて勉強し、その記録を [Zenn](https://zenn.dev) に公開するためのリポジトリです。

- 下書き: `drafts/`
- 公開済みの記事: `articles/`
- 運用ルール: [docs/workflow.md](docs/workflow.md)

```bash
npm install
npm run preview:drafts   # 下書きのプレビュー（http://localhost:8001）
npm run check            # 記事の一覧
```
