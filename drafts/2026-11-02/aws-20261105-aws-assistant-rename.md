# 🤖 AIの解説

| 項目 | 内容 |
|---|---|
| **要約** | マネジメントコンソールとモバイルアプリで使える Amazon Q Developer が、「AWS assistant」という名前に変わった |
| **料金** | 今のところ無料 |
| **対象** | 全世界。マネジメントコンソールと Console Mobile App |

:::details そもそもコンソールの Amazon Q Developer とは？
| 名前 | ひとことで |
|---|---|
| AWS マネジメントコンソール | ブラウザから AWS を操作する画面 |
| Amazon Q Developer（コンソール） | コンソールの横に出てくる AI のチャット。自分のアカウントの状況を見ながら、使い方の案内や操作の手伝いをしてくれる |
| AWS assistant | 今回からのその新しい名前 |
:::

**今回なにが変わった？**

| | これまで | これから |
|---|---|---|
| 名前 | Amazon Q Developer | AWS assistant |
| できること | アカウントに合わせた案内や操作 | 変わらない |
| 料金 | ― | 今のところ無料 |
| Pro のサブスクリプション | Amazon Q Developer Pro | 自動で引き継がれ、AWS assistant で Pro Tier の機能を使える |

**どんなときにうれしい？**
コンソールで「このエラーは何？」「このリソースの設定を見直したい」と思ったときに、画面を離れずに AI に聞けます。名前が変わっただけなので、これまで使っていた人は同じように使えます。

:::message
**確認ポイント**
