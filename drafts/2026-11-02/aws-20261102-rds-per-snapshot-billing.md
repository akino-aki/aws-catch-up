# 🤖 AIの解説

| 項目 | 内容 |
|---|---|
| **要約** | RDS のスナップショットの料金が、DB インスタンスごとのまとめではなく、スナップショット 1 つずつで分かるようになった |
| **料金** | 追加料金なし。すべてのスナップショットで最初から有効 |
| **対象** | すべての商用リージョンと GovCloud (US)。RDS のすべてのエンジン |

:::details そもそも RDS のスナップショットとは？
| 名前 | ひとことで |
|---|---|
| Amazon RDS | MySQL や PostgreSQL などのデータベースを、AWS がお世話してくれるサービス |
| スナップショット | ある時点のデータベースをまるごと保存したバックアップ。保存している容量に応じて料金がかかる |
| コスト配分タグ | リソースに付けたタグ（名札）ごとに、請求を分けて集計できる仕組み |
| Cost Explorer | AWS の料金をグラフや表で確認できる画面 |
:::

**今回なにが変わった？**

| | これまで | これから |
|---|---|---|
| 料金の見え方 | Cost Explorer やコストと使用状況レポート（CUR）で、DB インスタンスごとにまとめて表示 | スナップショット 1 つずつの料金が分かる |
| タグでの集計 | ― | スナップショットにコスト配分タグを付けて、目的ごとのバックアップ料金や予算と比べられる |

**どんなときにうれしい？**
「バックアップの料金がなぜか高い」というとき。どのスナップショットが料金を押し上げているかが分かるので、古い手動スナップショットを消すなどの判断がしやすくなります。

:::message
**確認ポイント**
Cost Explorer → サービスを RDS に絞り、リソース単位やタグ単位で表示してスナップショットの料金を探す
キーワード: Amazon RDS per snapshot billing cost allocation tags
:::
