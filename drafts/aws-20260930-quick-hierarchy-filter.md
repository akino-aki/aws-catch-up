# 🤖 AIの解説

| 項目 | 内容 |
|---|---|
| **要約** | 「地域 → 国 → 都市」のような絞り込みを、1 つの欄にまとめられるようになった |
| **料金** | 記載なし |
| **対象** | Amazon Quick が使えるすべてのリージョン（東京を含む） |

:::details そもそも Amazon Quick とは？
Amazon Quick（旧 Amazon QuickSight）は、データからグラフやダッシュボードを作る BI ツールです。Excel のグラフを、社内のみんなが Web で見られるようにしたもの、とイメージするとわかりやすいです。
:::

**今回なにが変わった？**

| | これまで | これから |
|---|---|---|
| 階層のある絞り込み | 階層ごとに別々の絞り込み欄を並べる | 1 つのドロップダウンにまとめられる（最大 5 階層） |
| 選び方 | 欄ごとに選ぶ | 親を選ぶと、子の選択肢が自動で絞り込まれる |

**どんなときにうれしい？**
「関東 → 東京都 → 渋谷区」のように、売上を地域ごとに掘り下げて見るダッシュボード。画面がすっきりして、クリックの回数も減ります。

:::message
**確認ポイント**
フィルターを追加 → 種類を「Hierarchy filter」にする → 項目を親から子の順に並べる
:::

# ✍️ 自分の調査・勉強結果

**Amazon Quick にサインアップした**

Quick を使ったことがなかったので、まずサインアップしました。30 日間はユーザー 25 人まで無料です。

![Amazon Quick のサインアップ画面](/images/aws-20260930-quick-hierarchy-filter/quick-signup.png)

サインアップの画面では、アカウント名と通知用メールアドレスを入れたあとにリージョンを変えると、確認のダイアログが出ます。ここで「OK」を押すと、入力したアカウント名とメールアドレスが消えました。**リージョンを先に選んでから、ほかの欄を入れる**のがおすすめです。

![リージョンを変えたときの確認ダイアログ](/images/aws-20260930-quick-hierarchy-filter/quick-signup-region-reset.png)

認証方法は「パスワードベースまたはシングルサインオン」にしました。この方法だと、コンソールにログインしている IAM のまま Quick に入れます。

![アカウントの作成が完了した画面](/images/aws-20260930-quick-hierarchy-filter/quick-signup-complete.png)

**従来のフィルターと階層フィルターを比べた**

「地方 → 都道府県 → 市区町村」と売上の列を持つ CSV（20 行）をアップロードして、表のビジュアルを作りました。そのうえで、同じデータに 2 種類のフィルターを作って比べました。

まず従来のやり方で、region・prefecture・city のフィルターを 1 つずつ作り、それぞれをシートの上部にコントロールとして追加しました。region で「関西」を選ぶと表は関西の行だけになりますが、prefecture の選択肢には北海道や東京都など、関西以外の県も全部残っています。3 つのフィルターは連動していません。

![従来のフィルター。region で関西を選んでも、prefecture には全部の県が出る](/images/aws-20260930-quick-hierarchy-filter/quick-separate-filters.png)

次に階層フィルターです。フィルターを追加して、フィルタータイプの「詳細フィルター」から「階層フィルター」を選び、「フィールド階層」に region → prefecture → city の順で並べます。

![階層フィルターの設定](/images/aws-20260930-quick-hierarchy-filter/quick-hierarchy-filter-settings.png)

シートに追加したコントロールを開くと、地方ごとに展開できるツリーになっていました。関西を開くと京都府・兵庫県・大阪府だけ、大阪府を開くと堺市・大阪市だけが出ます。チェックを付けたあと、最後に「適用」を押して反映する形です。

![階層フィルター。関西 → 大阪府 → 市とツリーでたどれる](/images/aws-20260930-quick-hierarchy-filter/quick-hierarchy-filter-tree.png)

|          | 従来（フィルターを並べる）               | 階層フィルター                    |
| -------- | --------------------------- | -------------------------- |
| コントロールの数 | 階層の数だけ（今回は 3 つ）             | 1 つ                        |
| 選択肢の連動   | しない（今回の設定では）                | する。親を開くと、その子だけが出る          |
| 選び方      | 欄ごとにチェックを付け外しする             | ツリーでチェックを付け、「適用」を押す        |
| 作り方      | フィルターを階層の数だけ作り、それぞれシートに追加する | フィルターを 1 つ作り、フィールド階層に列を並べる |

従来のフィルターも、設定で選択肢を連動させる（カスケード）ことはできるようです。ただ、連動させても欄の数は変わりません。階層フィルターは、親子関係がツリーで見えるので、どの県がどの地方かを知らなくても迷わず選べるのがよいと思いました。
