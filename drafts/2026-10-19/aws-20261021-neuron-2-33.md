# 🤖 AIの解説

| 項目 | 内容 |
|---|---|
| **要約** | AWS の AI 用チップ Trainium で、ふつうの PyTorch のコードをそのまま動かせる TorchNeuron がパブリックベータになった。ほかに故障をすばやく見つける Neuron Observer なども追加 |
| **料金** | Neuron（ソフトウェア）は無料。使うインスタンスの料金はかかる |
| **対象** | EC2 Trn2 / Trn3 インスタンス |

:::details そもそも Neuron と Trainium とは？
| 名前 | ひとことで |
|---|---|
| AWS Trainium | AWS が自分で作った、AI の学習（と推論）向けのチップ。Trn2 / Trn3 インスタンスで使う |
| AWS Neuron | Trainium や Inferentia で AI モデルを動かすためのソフトウェア一式（コンパイラ・ライブラリ・ツール） |
| PyTorch | AI モデルを作るときに最もよく使われているライブラリの 1 つ |
| torch-xla | PyTorch を GPU 以外のチップで動かすための橋渡し。これまでの Neuron はこれを使っていた |
| vLLM | 大規模言語モデルを速く動かすための推論エンジン |
| NKI | Neuron 向けに、自分で計算処理（カーネル）を書くためのしくみ |
:::

**今回なにが変わった？**

| 項目 | 内容 |
|---|---|
| TorchNeuron（ベータ） | torch-xla を経由せず、ふつうの PyTorch で Trainium を使える。eager モード[^eager]と torch.compile の両方に対応 |
| Neuron Observer（ベータ） | Trainium の調子の悪さを 1 秒以内に見つけ、どのノード・デバイスかを特定する |
| vLLM | vLLM 0.29.0 に対応。動画生成モデル Wan2.2 向けのプラグインも同梱 |
| 開発環境 | TorchNeuron・PyTorch 2.14・TorchTitan 入りの AMI とコンテナを新しく用意 |
| Neuron Explorer | torch.profiler の結果を開ける。メモリ不足の原因を Python のソースの行まで追える |
| NKI | Python の機能をフルに使ってカーネルを書ける。実験的なカーネルを 25 個追加 |

**どんなときにうれしい？**
GPU 向けに書いた PyTorch の学習コードを、Trainium でも試してみたいときです。これまでは torch-xla 向けの書き方に合わせる必要がありましたが、デバイスの指定を変えるくらいで動かせるようになり、Trainium を試すハードルが下がります。

:::message alert
TorchNeuron と Neuron Observer はパブリックベータです。また週刊AWS の紹介では、次の Neuron 2.34 で Trn2 / Trn3 の Torch/XLA を使った推論の経路と NxD Inference のサポートが終わる予告が出ているとのことなので、今の経路を使っている場合は移行の計画が必要です。
:::
