# 🤖 AIの解説

| 項目 | 内容 |
|---|---|
| **要約** | アプリと AI エージェントの状態をまとめて見られる CloudWatch Omni が、東京を含む 8 リージョンで使えるようになった |
| **料金** | VS Code・Cursor・Kiro 向けの拡張機能は無料。サービス自体の料金は CloudWatch Omni の料金ページを参照 |
| **対象** | 既存の 3 リージョン（バージニア北部・オレゴン・アイルランド）＋ 新しい 8 リージョン（東京・シンガポール・シドニー・ムンバイ・フランクフルト・ロンドン・カナダ中部・サンパウロ）＝ 11 リージョン |

:::details そもそも CloudWatch Omni とは？
| 名前 | ひとことで |
|---|---|
| オブザーバビリティ（可観測性） | システムの中で何が起きているかを、ログ・メトリクス・トレースなどから外から分かるようにすること |
| CloudWatch Omni | チームとアプリ単位で整理された、AI を活用したオブザーバビリティの画面。AWS コンソールとは別の Web 画面（SSO でログイン）か、IDE の拡張機能で使う |
| スペース | Omni で見るための入れ物。中央のアカウントに作ると、複数のアカウント・リージョン・他のクラウド（Azure・GCP）のデータもまとめて見られる |
| OpenTelemetry[^otel] | ログやトレースを集めるための、業界共通のしくみ |
:::

**今回なにが変わった？**

| | これまで | これから |
|---|---|---|
| 使えるリージョン | 3 リージョン（米国・欧州のみ） | 11 リージョン（東京を含む） |
| 日本から使うとき | スペースを海外のリージョンに作る必要があった | 東京リージョンにスペースを作れる |

**どんなときにうれしい？**
データを置く場所を日本国内にしたい場合や、東京リージョンで動かしているアプリを近いリージョンで見たい場合です。LangGraph や Strands などで作った AI エージェントの動きも、アプリのメトリクスと同じ画面で追えます。

:::message alert
使い始めるには、CloudWatch コンソールで Omni のスペースを作り、SSO（IAM Identity Center など）を設定する必要があります。
:::

:::message
**確認ポイント**
CloudWatch コンソール → CloudWatch Omni → スペースの作成画面で、リージョンに東京が選べるか
キーワード: CloudWatch Omni space, SSO, IDE extension
:::
