# 🤖 AIの解説

| 項目 | 内容 |
|---|---|
| **要約** | OpenAI の新しいモデルが Bedrock で使えるようになった |
| **料金** | 100 万トークンあたり 入力 $2.00 / 出力 $10.00（Global CRIS[^cris] の場合、週刊AWS より） |
| **対象** | 対応リージョンは Bedrock のドキュメントで確認 |

:::details そもそも Amazon Bedrock とは？
いろいろな会社の生成 AI モデルを、AWS 上から API で呼び出せるサービスです。
:::

**今回なにが変わった？**
OpenAI の新しいモデル **GPT-6.1 Sol** が使えるようになりました。

| 項目 | 内容 |
|---|---|
| 得意なこと | AI が自分でコードを書いて直す作業（エージェンティックコーディング）、パソコン画面の操作（computer use）、文書作成などの業務 |
| コスト | 上位モデルの GPT-6 Astra に近い性能を、およそ 5 分の 1 の料金で |
| プロンプトキャッシュ | 同じ前置き（指示文など）を何度も送るとき、使い回して安く速くする機能に対応 |

**どんなときにうれしい？**
AI エージェントのように、何度もモデルを呼び出すシステム。1 回あたりの料金が安いほど、全体のコストが大きく下がります。

:::message
**確認ポイント**
Bedrock コンソール →「モデルカタログ」
キーワード: クロスリージョン推論、プロンプトキャッシュ
:::

# ✍️ 自分の調査・勉強結果

**画面**

Bedrock のモデルカタログで「GPT-6.1」と絞り込むと、東京リージョンに「新規」のラベル付きで載っていました。カードには「サーバーレス」「クロスリージョン推論」とあります。

![Bedrock のモデルカタログで GPT-6.1 Sol を絞り込んだ画面](/images/aws-20260929-bedrock-gpt-6-1-sol/bedrock-model-catalog-gpt-6-1-sol.png)

詳細ページのカテゴリには、考える深さを low / medium / high / xhigh / max の 5 段階で選べる（five effort levels）とありました。

![GPT-6.1 Sol の詳細ページ](/images/aws-20260929-bedrock-gpt-6-1-sol/bedrock-gpt-6-1-sol-detail.png)

モデルの追加以外では、公式発表に明示的なプロンプトキャッシュに対応したことが書かれていました。また、モデルカタログの上には、最新の Anthropic や OpenAI のモデルは bedrock-mantle エンドポイント向けの新しいコンソールで、という案内が出ていました。

**プレイグラウンドで呼び出してみた**

プレイグラウンドで「インターネットで調べて」と頼むと、できないと言われました。モデル自体はインターネットにつながっていないので、これは正常な動きです。ChatGPT のアプリなどでネット検索ができるのは、アプリ側が検索の仕組みを用意して、モデルに使わせているからです。カテゴリにあった「agentic search」も、検索の道具を渡されたら上手に使える、という意味で、最初から検索できるという意味ではありませんでした。

ネット検索をさせたいときは、ツール使用（Tool use）で検索の関数を渡したり、AgentCore などでエージェントを組んだりする必要があります。

**プレイグラウンドで試せること・試せないこと**

| 試せる | 試せない |
|---|---|
| 推論、文章の質、コード、こちらが貼り付けた資料の読み取り | ネット検索や外部 API を使う動き（ツール使用やエージェントが必要） |
| システムプロンプトや effort などの設定の違い | 自分のデータを検索させる（ナレッジベースなどが必要） |
| 「Compare models」で複数のモデルを並べて比べる | 大量の質問での正解率（モデル評価の機能を使う） |

調べてほしい情報は、自分で貼り付けて渡せば、モデルの力そのものは確かめられます。
