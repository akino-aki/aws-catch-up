# 🤖 AIの解説

| 項目 | 内容 |
|---|---|
| **要約** | 最新の AMD CPU を積んだサーバーで、データベースを動かせるようになった |
| **料金** | インスタンスの通常料金（詳細は RDS の料金ページ） |
| **対象** | RDS for PostgreSQL / MySQL / MariaDB。東京を含む 9 リージョン |

:::details そもそもインスタンスタイプの名前の読み方は？
RDS ではデータベースを動かすサーバーの性能を「インスタンスタイプ」で選びます。`M8a` は次のように読みます。

| 文字 | 意味 |
|---|---|
| M | CPU とメモリのバランスが取れた汎用タイプ |
| 8 | 世代（数字が大きいほど新しい） |
| a | AMD 製の CPU |
:::

**今回なにが変わった？**

| 項目 | M8a の特徴 |
|---|---|
| CPU | 第 5 世代 AMD EPYC |
| 仮想 CPU | 1 つが物理コア 1 つにそのまま対応。ほかの処理と CPU を取り合わない |
| 最大サイズ | 192 vCPU / メモリ 768 GiB |
| 通信速度 | ネットワーク最大 75 Gbps、ストレージ（EBS）最大 60 Gbps |

**どんなときにうれしい？**
データベースの性能を上げたい、または同じ性能をより安く手に入れたいとき。インスタンスタイプを変えるだけで試せます。

:::message
**確認ポイント**
RDS コンソールでデータベースを「変更」→「DB インスタンスクラス」
キーワード: インスタンスタイプの命名規則、Graviton・AMD・Intel の違い
:::
