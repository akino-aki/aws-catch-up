# 🤖 AIの解説

| 項目 | 内容 |
|---|---|
| **要約** | Cognito のユーザープールで、ユーザーのログイン中のセッションを一覧で見たり、個別に終わらせたりできるようになった |
| **料金** | 発表には記載なし（Essentials または Plus プランが必要） |
| **対象** | Essentials / Plus プランのユーザープール。Cognito が使えるすべてのリージョン |

:::details そもそも Amazon Cognito とは？
| 名前 | ひとことで |
|---|---|
| Amazon Cognito | アプリにログイン機能を付けるためのサービス |
| ユーザープール | アプリの利用者（ユーザー）の名簿とログインの設定をまとめたもの |
| セッション | 「ログインしている状態」のこと。ログインのたびに作られる |
| managed login | Cognito が用意してくれるログイン画面 |
| SSO セッション | managed login でログインしたときにできるセッション。ほかのアプリにもログインし直さずに入れる[^sso] |
| トークンセッション | アプリにログインしてトークン（入館証のようなもの）を受け取ったときにできるセッション |
:::

**今回なにが変わった？**

| | これまで | これから |
|---|---|---|
| セッションの確認 | ― | ユーザーの全デバイス・全アプリのセッションを一覧で見られる（デバイスの種類、最後に使った日時と場所、最初のログイン日時など） |
| セッションの終了 | ― | 個別に失効できる。関連するセッションごと、または全部まとめて（グローバルサインアウト）も終わらせられる |
| SSO セッションを使い回す期間 | 1 時間で固定 | アプリクライアントごとに設定できる |
| 同時のセッション数 | ― | ユーザーごとのトークンセッションの上限を決められる |

**どんなときにうれしい？**
「スマホをなくしたので、そのスマホだけログアウトさせたい」というとき。利用者に「ログイン中の端末一覧」を見せる画面も作りやすくなります。同時にログインできる数を絞って、アカウントの使い回しを防ぐこともできます。

:::message alert
Essentials または Plus プランのユーザープールでのみ使えます。週刊AWS の紹介では、セッションの追跡はユーザープールごとに有効にしてから使うとされています。
:::

:::message
**確認ポイント**
Amazon Cognito コンソール → ユーザープール → ユーザー → 個々のユーザーのセッション
キーワード: Amazon Cognito session management, global sign-out
:::
