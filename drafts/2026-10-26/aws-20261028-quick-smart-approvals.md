# 🤖 AIの解説

| 項目 | 内容 |
|---|---|
| **要約** | Amazon Quick に「スマート承認」が加わった。エージェントがやろうとする操作を別の審査用のモデルが見て、よくある操作は自動で承認し、影響の大きい操作だけ人に確認する |
| **料金** | What's New には記載なし |
| **対象** | Amazon Quick のエージェント機能が使えるすべてのリージョン |

:::details そもそも Amazon Quick とスマート承認とは？
| 名前 | ひとことで |
|---|---|
| Amazon Quick | 社内のデータを使って質問に答えたり、作業を代わりにやってくれたりする AWS の AI アシスタントのサービス |
| エージェントの操作 | メールの送信、記録の更新、チケットの作成など、AI がユーザーの代わりに行う操作 |
| classifier | スマート承認で、操作がユーザーの依頼に合っているかを審査する、別の AI のモデル |
:::

**今回なにが変わった？**

| | これまで | これから |
|---|---|---|
| 「毎回確認する」設定の操作 | 毎回ユーザーが承認 | classifier が審査し、よくある操作は自動で承認 |
| 人に回される操作 | ― | 組織の外への送信、権限の変更、削除、支払い、依頼の範囲を超える操作など。審査の失敗・時間切れのときも人に回る |
| 既存の設定 | ― | 常に優先。拒否は拒否のまま、新しい権限を与えることはない |
| 記録 | ― | 自動の承認と設定の変更はすべて CloudTrail に残る |

**どんなときにうれしい？**
エージェントに作業を任せるたびに承認ボタンを押し続けて、だんだん中身を見ずに押すようになる「承認疲れ」を防ぎたいとき。本当に確認すべき操作にだけ集中できます。

:::message alert
すべてのユーザーで最初からオンになっています。オフにしたい場合は、管理者がカスタムの権限で使える人を絞るか、ユーザーがチャットのオプションで会話や定期実行ごとにオフにします。
:::
